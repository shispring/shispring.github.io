最佳实践

场景 命令 作用 重点关注指标
TCP默认测试 iperf3 -c <IP> 基础吞吐测试 Bitrate、Retr
TCP持续输出 iperf3 -c <IP> -i 1 每秒统计 Bitrate波动
TCP双向 iperf3 -c <IP> --bidir 同时测试收发 上传/下载吞吐
TCP反向 iperf3 -c <IP> -R 服务端→客户端 下载能力
多流TCP iperf3 -c <IP> -P 8 多连接压测 聚合带宽
长时间稳定性 iperf3 -c <IP> -t 300 稳定性测试 是否掉速
UDP基础 iperf3 -u -b 100M -i 1 UDP发送100 Mbps Lost、Jitter
UDP压满链路 iperf3 -u -b 0（若版本支持）或 -b 1G/10G 极限UDP 丢包率
指定MSS iperf3 -M 1460 测试MSS影响 吞吐、重传
指定窗口 iperf3 -w 4M 调整TCP窗口 高延迟链路性能
指定CPU亲和 iperf3 -A 0 固定CPU 排查CPU瓶颈
零拷贝 iperf3 -Z 减少CPU开销 高带宽测试
JSON输出 iperf3 -J 自动化采集 便于脚本解析
IPv6 iperf3 -6 -c <IPv6> IPv6性能 吞吐、丢包

常见字段说明

字段 TCP UDP 含义 是否重点关注
Interval ✔ ✔ 当前统计时间窗口 一般
Transfer ✔ ✔ 当前时间段传输的数据量 ✔
Bitrate ✔ ✔ 当前时间段平均带宽 ✔✔✔
Retr ✔ ✘ TCP重传次数，越少越好 ✔✔✔
Cwnd ✔ ✘ TCP拥塞窗口大小，反映发送窗口 ✔✔
Jitter ✘ ✔ UDP抖动，越小越好 ✔✔✔
Lost/Total Datagrams ✘ ✔ UDP丢包数/总包数 ✔✔✔
Total Datagrams ✘ ✔ UDP发送的数据报总数 一般
sender / receiver ✔ ✔ 发送端/接收端统计汇总 ✔
