概念解析

1. 集群核心控制组件

缩写 完整英文 中文名称 核心作用
MON Monitor 监控节点 集群总元数据中心，保存集群拓扑、认证、存储池配置，仲裁集群状态，端口6789
MGR Manager 管理节点 集群管理、Dashboard、Prometheus监控、调度任务，对外API
OSD Object Storage Daemon 对象存储守护进程 真正承载数据，单块磁盘对应一个OSD，负责数据三副本/纠删码、PG数据读写
MDS Metadata Server 文件元数据服务 仅CephFS分布式文件系统使用，管理目录、文件元数据
RGW Rados Gateway 对象存储网关 基于底层RADOS封装S3/Swift标准HTTP接口，对外提供对象存储服务

2. 底层存储核心概念

缩写 完整英文 中文 说明
RADOS Reliable Autonomic Distributed Object Store 可靠自主分布式对象存储 Ceph底层内核，所有数据（块/文件/对象）最终都存在RADOS对象
PG Placement Group 放置组 数据分片最小单元，OSD之间数据均衡、副本同步的载体
Pool Storage Pool 存储池 逻辑资源隔离分区，RBD/CephFS/RGW分别使用独立Pool
RBD Rados Block Device 分布式块设备 基于RADOS的块存储，等价云硬盘，供虚拟机/K8s PVC使用
CephFS Ceph File System Ceph分布式文件系统 POSIX标准共享文件存储，多节点同时挂载读写目录

3. 对象存储 RGW / S3 专属名词

术语 完整英文 中文
Bucket Bucket 存储桶
Object Object 对象
AK Access Key 访问密钥ID
SK Secret Key 私有密钥
REST API Representational State Transfer API 标准化HTTP接口

4. 权限/认证相关

术语 全称 中文
Keyring Keyring 密钥环
Client Client Ceph客户端账号
CSI Container Storage Interface 容器存储标准接口
JWT JSON Web Token 加密令牌

5. 镜像/块存储专属名词

术语 全称 中文
Image RBD Image RBD镜像
Snapshot Snapshot 快照
Feature Image Feature 镜像特性
